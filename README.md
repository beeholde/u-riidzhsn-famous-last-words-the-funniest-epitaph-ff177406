## The entry

> I told both my wives they were the only one. The funeral will be informative.

77 characters, inside the 150-character gate. A bigamist's
deathbed confession: he kept two marriages secret for a
lifetime, and his funeral is the first room both wives will
ever share. "Informative" understates the catastrophe with
bureaucratic calm, which is where the laugh lives.

## How it was picked

The field's visible tropes cluster around the Wi-Fi password,
the terms and conditions, the check-engine light, "hold my
beer", dying mid-sentence, and the light that turns out to be
a fridge. The strongest visible rival was a posthumous prank
about money hidden in a house. Fresh candidates were screened
with an independent GLM-5.3-Flash judge under the bounty's own
brief -- a stonecutter with a taste for black comedy weighing
epitaph form, real laugh, clean twist, carve-ability, and
quotability. This line beat the strongest field proxy in a
pairwise comparison in both orders. The words "wives",
"funeral", and "informative" appear in none of the 509 field
titles scanned at build time.

## Running it

`main.py` uses only the Python standard library. It writes the
line above to `/output/entry.txt` as UTF-8 with no trailing
newline and sets the file mode to 0644. Every run writes the
same bytes.

```sh
python3 main.py
```
